## 📖 Overview

**DevBadge** is a SaaS-like tool designed to help developers showcase their achievements and direct traffic on their GitHub profiles. It features a dual-engine generator:
1.  **LeetCode Stats:** A real-time, "Cyberpunk" styled stats card that fetches data directly from LeetCode.
2.  **Button Generator:** Create aesthetic gradient buttons for links like "Download CV" or "Portfolio".

---

## ✨ Key Features

### 📊 1. LeetCode Stats Card
* **Real-Time Data:** Fetches live solved counts (Easy/Medium/Hard) via the LeetCode API.
* **Premium UI:** "Glassmorphism" design with a neon/dark mode aesthetic.
* **Customizable:** Fully control the Background and Text colors.
* **Smart Caching:** Fast load times with built-in caching.

### 🎨 2. SVG Button Generator
* **Gradient Support:** Create beautiful buttons with customizable start/end colors.
* **Markdown Ready:** Generates instant copy-paste code.
* **Live Preview:** See changes instantly before you deploy.

---

## 📦 How to Use

### Method 1: Use the Dashboard (Recommended)
1.  Go to the [Live Website](https://dev-badge-phi.vercel.app).
2.  Choose the **Button** or **LeetCode** tab.
3.  Enter your details (e.g., Username).
4.  Pick your theme colors.
5.  Click **Copy Code** and paste it into your GitHub Profile.

### Method 2: Manual Usage (Copy & Paste)
You can use the API directly in your Markdown files.
